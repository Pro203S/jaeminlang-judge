# 점수 제도

문제를 처음 정답 처리하면 해당 문제의 난이도에 맞는 점수가 더해집니다. 이미 푼 문제를 다시 맞혀도 점수는 추가되지 않습니다.

## 계산식

점수는 다음 방식으로 계산합니다.

```txt
카테고리 기본값 ^ 2 * (6 - 단계)
```

| 카테고리 | 기본값 |
| --- | --- |
| 브론즈 | 1 |
| 실버 | 2 |
| 골드 | 3 |
| 플레티넘 | 4 |
| 다이아몬드 | 5 |
| God | 6 |

단계는 V가 5, I이 1입니다. 그래서 같은 카테고리에서는 I이 가장 높은 점수를 줍니다.

## 예시

- 브론즈 V: `1 * 1 * 1 = 1`
- 실버 III: `2 * 2 * 3 = 12`
- 골드 I: `3 * 3 * 5 = 45`
- God I: `6 * 6 * 5 = 180`
