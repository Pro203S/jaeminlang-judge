# 재민랭 문법

이 문서는 재민랭의 **기초** 문법만 알려줍니다.  
더 심화된 문법을 알고싶으시면 [재민랭 공식 문서](https://github.com/Pro203S/jaeminlang#jaeminlang)를 참고해주세요.

## 기본 문법

재민랭의 기본 문법은 `키워드,파라메터,파라메터2,파라메터3...` 입니다.  
`,`로 나눠집니다.  
한 줄에 한 개의 키워드가 들어가있습니다.  

문자열을 표현하려면 `"` 사이에 문자열을 입력하면 됩니다.  
문자열 안에 `,`를 넣으려면 이스케이프 처리해야합니다.  
예시: `"안산\, 재민 그리고 재민랭"`  

`NULL`을 표현하려면 `여친` 키워드를 사용해야합니다.  

## 출력 (안산)

`안산` 키워드를 사용해 문자열을 출력할 수 있습니다.  
파라메터에는 변수 이름 또는 문자열 하나만 들어갈 수 있습니다.  
`stdout`에 출력됩니다. 또한 줄바꿈을 하고싶으면 `\n`을 출력해야합니다.  

코드 예시:
```
안산,"Hello World"
안산,변수명
```

`안산,"Hello World"`는 `Hello World`를 출력합니다.  
`안산,변수명`은 `변수명`에 들어있는 값을 출력합니다.  

## 입력 (재민)

`재민` 키워드를 사용해 문자열을 입력할 수 있습니다.  
파라메터에는 변수 이름이 들어갈 수 있습니다.  

한 줄 씩 입력됩니다.  

코드 예시:
```
재민,입력
안산,입력
```

`재민,입력`은 `입력`에 입력된 값을 저장됩니다.  
`안산,입력`은 `입력`을 출력합니다.  

## 그램 (변수)

`그램` 키워드를 사용해 변수를 선언하고, 대입할 수 있습니다.  
파라메터에는 변수에 지정할 값이나 수식이 들어갈 수 있습니다.  

### 수식

들어갈 수 있는 수식의 형식은 `<연산자><피연산자>`입니다.  
예시: `*3`, `+2`, `-1`, `^7`  
(여기서의 `^`은 제곱을 뜻합니다)  

코드 예시:
```
그램,a,1
그램,a,*5

안산,a
```

이때 `a`는 `5`가 됩니다. (1 * 5 = 5)

## 러스트 (반복문, 조건문)

`러스트` 키워드를 사용해 반복문 또는 조건문을 구현할 수 있습니다.  
파라메터에는 값1, 값2, 이동할 줄 번호가 들어갑니다.  

값1과 값2가 같지 않을 때, 주어진 줄 번호로 이동합니다.  

코드 예시:
```
그램,i,0
안산,"반복문 테스트\n"
그램,i,+1
러스트,i,5,2
```

위 코드는 `반복문 테스트`를 5번 출력합니다.
